JUNGLE MARBLE SHOOTER — PHONE EDITION

Open index.html in a modern browser. On a phone, use the HTTPS preview URL and choose Add to Home Screen / Install app.

CONTROLS:
- Touch or drag to aim; tap to shoot.
- Swap changes the loaded marble.
- Pause pauses the game; Restart resets it.
- Match 3 or more marbles of the same colour.

The app is self-contained. HTTPS hosting is required for installable PWA and offline service-worker features.
